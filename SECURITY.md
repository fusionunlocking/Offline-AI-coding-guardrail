# Security boundaries

This repository is an **offline demonstration**. Do not use its planner output to unlock an engineering lane, waive independent acceptance, or promote a production candidate.

The input document is untrusted and is schema-checked but not cryptographically authenticated. The local ledger is tamper-evident in a limited, non-adversarial sense only. No secrets are required or should be supplied.

Report safety bugs privately to the repository owner. Do not publish NEXUS worktree paths, trading credentials, owner ledgers or proprietary implementation details in issues.
